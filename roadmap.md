# Roadmap

## План работ от 2026-07-24

Цель: довести `ScannerAI` до рабочего публикационного MVP без глубокой полировки, с реальным AI-сервером, серверной проверкой подписок RuStore и отладкой основных функций приложения.

Оценка из обсуждения: 12-16 рабочих дней на одного разработчика, реалистично заявлять 15 рабочих дней. С запасом на неизвестные баги и RuStore: 16-18 рабочих дней.

### 1. Ktor-сервер для AI и подписок

- Реализовать небольшой Ktor-сервер вместо текущего минимального FastAPI-прокси или как его замену.
- Добавить конфигурацию окружений, Docker и базовый production-ready запуск.
- Использовать локальную SQLite-базу.
- Завести таблицы пользователей/устройств, подписок, AI-запросов, статистики и ошибок.
- Реализовать авторизацию запросов приложения через серверный access token.
- Перенести три AI-сценария: summary, extract, contract.
- Сохранить текущий принцип приватности: изображения не отправляются, тексты документов не пишутся в логи.
- Добавить лимиты запросов, журналирование объема текста, ошибок и примерной стоимости.
- Добавить закрытые admin-эндпоинты через Swagger UI без отдельной админ-панели.
- Подготовить деплой, HTTPS, env-конфиги и базовую проверку.

Оценка: 5-7 рабочих дней.

### 2. Серверная проверка подписок RuStore

- Мигрировать платежную связку на актуальный RuStore Pay SDK/API.
- Передавать на сервер `purchaseId`, ID продукта и внутренний `appUserId`.
- Получать и использовать серверный Public API token RuStore.
- Проверять подписку через RuStore API V4.
- Разделить sandbox и production-окружения.
- Кэшировать статус подписки, чтобы не ходить в RuStore перед каждым AI-запросом.
- Корректно обрабатывать окончание подписки, отмену, отсутствие подписки и временные ошибки RuStore.
- Сделать сервер источником истины для допуска к AI.

Оценка: 2-3 рабочих дня.

### 3. Android: подключение AI к новому серверу

- Переключить Android AI-клиент с текущего прокси на новый Ktor-сервер. Реализовано 2026-07-24.
- Добавить авторизацию AI-запросов и обработку обновления/получения токена. Реализовано 2026-07-24.
- Обрабатывать серверные ошибки лимитов, подписки, авторизации и временной недоступности. Базовая обработка реализована 2026-07-24; отдельное состояние серверного лимита остаётся.
- Сохранить три режима AI: краткое содержание, извлечение реквизитов, анализ договора. Реализовано 2026-07-24.
- Не ломать debug mock AI, но исключить mock-поведение из release. Реализовано 2026-07-24.

Оценка: входит в Android-блок 3-4 рабочих дня.

### 4. Android: платежные экраны и Premium

- Перенести текущий репозиторий покупок на актуальный RuStore Pay SDK.
- Связать успешную покупку с серверной валидацией подписки. Android-связка и debug mock реализованы 2026-07-24; настоящая серверная проверка RuStore остаётся.
- Доработать состояния экранов: загрузка, покупка, отмена, ошибка, восстановление, активная подписка.
- Показывать понятные ошибки при отсутствии подписки, проблемах RuStore и недоступности сервера.
- Проверить месячную и годовую подписку.

Оценка: входит в Android-блок 3-4 рабочих дня.

### 5. Отладка основных функций приложения

- Проверить камеру и live-контур документа.
- Проверить ручной crop, повороты, перспективу и фильтры.
- Проверить импорт изображений из галереи.
- Проверить многостраничные документы, перестановку и удаление страниц.
- Проверить экспорт PDF и Sharesheet.
- Проверить OCR rus/eng на реальных документах.
- Проверить AI по всем трем режимам после OCR.
- Проверить покупку, восстановление подписки, окончание/отсутствие подписки.
- Проверить release-сборку с R8.
- Проверить минимум на двух реальных устройствах.

Оценка: 3-5 рабочих дней.

### 6. Известные хвосты из аудита

- Автоснимок не реализован: сейчас есть стабильная детекция кадров, но нет вызова съемки.
- Ручной режим не полностью ручной: после снимка все равно запускается автодетект границ.
- Превью фильтров в UI упрощено через `ColorMatrix` и может отличаться от финального OpenCV-результата.
- Drag-and-drop страниц работает базово и плохо подходит для длинных документов.
- AI не запускает OCR автоматически: пользователь должен сначала выполнить OCR.
- AI-результаты не сохраняются и исчезают после закрытия экрана.
- Язык AI сейчас фактически захардкожен на русский.
- Продуктовая аналитика не подключена: используется debug-реализация.
- README содержит ошибочные Gradle-параметры RuStore: нужны `-Prustore...`, а не `-Prostore...`.
- Автотесты не покрывают реальные камеры, длинные PDF, системный picker, Sharesheet, backend AI и настоящий RuStore Billing.

### 7. Не входит в текущий план

- Полноценные аккаунты с email или телефоном.
- Перенос подписки между произвольными устройствами вне механизмов RuStore.
- Отдельная админ-панель.
- Облачная БД.
- Серверные уведомления RuStore.
- Сложные тарифы, дневные и месячные квоты.
- Глубокая полировка камеры и качества OCR до уровня коммерческого сканера.
